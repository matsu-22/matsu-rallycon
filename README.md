# Matsu RallyCon v0.5.2 PDF

PDFコマ図をiPhoneで見るための試作版です。イベントごとにPDFを差し替えて利用できます。

## 今回の改良
- 中央PDFビューアのレイアウトを修正
- 左パネルを5段構成に修正し、下部ボタンとの重なりを解消
- 1本指ドラッグでPDFを上下左右へ移動（Fit時でも、ページが画面より大きい場合は移動可能）
- 2本指ピンチで0.5～400%ズーム
- ダブルタップでFit / 200%
- 拡大中もPDFを直感的に移動可能
- PDFページ送り、PDF読込、TOTAL/LEG/SPEED/TIME、CAP、距離補正、AUTO NEXTを維持

## iPhoneでの操作
1. PDF読込を押す
2. 「ファイル」からイベントのPDFを選択
3. PDF上を1本指でドラッグして上下左右に移動
4. 2本指でピンチして拡大縮小
5. ダブルタップでFit/200%を切替

## 注意
現在のコマ索引はコマ練Classic2026のサンプルデータを内蔵しています。別イベントのPDFでもPDF表示自体は利用できますが、TOTALから現在コマを自動判定する汎用PDF解析は今後の改良項目です。
