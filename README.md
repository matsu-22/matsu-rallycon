# Matsu RallyCon v0.5.3 PDF

PDFコマ図をiPhoneで実戦的に閲覧する試作版。

## 今回の修正
- PDFは**横幅いっぱいを基準**に表示し、A4縦長の下側も指で上下ドラッグして確認可能
- 1本指ドラッグ：PDFを上下左右へ移動
- 2本指ピンチ：拡大・縮小
- ダブルタップ：WIDTH / 200%
- ページ送り、PDF読込、TOTAL/LEG、CAP、AUTO NEXT、現在地同期
- iPhone Safe Area対応

## 使い方
1. GitHub Pagesで公開した `index.html` を置き換える。
2. iPhoneで横画面で開く。
3. PDF読込からイベントのPDFを選択。
4. コマ図中央を指で上下にドラッグして下側のコマを確認する。

※PDF解析・コマ位置の自動フォーカスは今後さらに精度を上げる予定。
